Los 10 pasos (Tanenbaum 3.6.2)

    Ideas clave para el examen

    • El orden para recitar: trap (el hardware guarda el PC) → ensamblador guarda los registros → el SO averigua la página virtual → valida dirección y protección → busca marco (reemplazo si no hay) → si está sucia, la escribe y cambia de proceso → lee la página del disco (y vuelve a cambiar de proceso) → con la interrupción de disco actualiza la tabla → respalda la instrucción (PC al inicio) → planifica el proceso → el ensamblador recarga los registros y vuelve a modo usuario.
    • ⚠️ Durante las dos esperas de disco (escritura de la sucia y lectura de la nueva) el proceso que falló queda BLOQUEADO y la CPU la usa otro proceso. Cuando el disco termina pasa a LISTO, no directo a ejecución. El marco se marca ocupado para que nadie lo use mientras tanto.
    • 🧠 Conexión con la U1 y la U2: los pasos 1–2 y 9–10 son el mismo esquema que el tratamiento de una interrupción y el cambio de contexto. El fallo de página es un trap (excepción sincrónica), no una interrupción de un dispositivo.
    • ⚠️ Respaldo de instrucción: al fallar, el PC puede valer 1000, 1002 o 1004 según qué operando falló (fig. 3-28), y puede haber autoincrementos a medio hacer. Algunas CPU guardan el PC de inicio en un registro oculto; si no, el SO tiene que deducirlo.

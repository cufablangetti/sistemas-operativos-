Traducción de dirección virtual a física

Escribí una dirección (en hexa con 0x, en binario con 0b o en decimal), elegí el tamaño de página y avanzá con Siguiente paso: el simulador la pasa a binario, la corta en página y desplazamiento, busca la página en la tabla (podés editar los marcos y el bit de presente) y arma la dirección física con el marco. Es el ejercicio típico de la cátedra. (Tanenbaum, cap. 3.3.1–3.3.2, págs. 189–194)

    Cambiá el marco o destildá «P» para provocar un fallo de página.

    Ideas clave y frases de examen

    • 🧠 Se reemplaza el número de página por el número de marco; el desplazamiento no se toca.
    • Bits de desplazamiento = log₂(tamaño de página): 1 KB → 10, 2 KB → 11, 4 KB → 12. El resto, a la izquierda, es el número de página.
    • ⚠️ Cortá desde la derecha: el desplazamiento son los bits de menor orden. Error típico: contar los bits de página desde la izquierda con el tamaño equivocado.
    • ⚠️ Si el bit de presente/ausente es 0 hay fallo de página: no hay dirección física hasta que el SO traiga la página (y, si lo piden, se aplica el algoritmo de reemplazo).
    • Comprobación rápida: física = marco × tamaño de página + desplazamiento.

      Ideas clave y frases de examen

      • Óptimo: saca la página que se va a usar más tarde. Es imposible de implementar porque el SO no conoce el futuro, igual que SJF. Sirve como referencia para comparar los demás.
      • FIFO saca la que llegó primero, aunque se use todo el tiempo. Por eso casi no se usa puro. Segunda oportunidad es FIFO mirando el bit R: con R = 1 la página se salva una vez.
      • ⚠️ En segunda oportunidad, la página salvada va al final con R = 0 y su llegada pasa a ser el instante actual. Si todas tienen R = 1, degenera en FIFO, pero siempre termina.
      • Reloj = segunda oportunidad sin mover páginas: una lista circular y una manecilla. Saca las mismas víctimas, pero es más eficiente.
      • 🧠 En el examen solo compiten las páginas presentes (P = 1). Si la víctima tiene M = 1, se escribe al disco. La dirección física se arma con el marco, no con el número de página.
